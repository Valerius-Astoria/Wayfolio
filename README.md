### Project Overview
This is an adventure planning and journaling app built with SwiftUI, MapKit, and SwiftData. Users can search for places with Apple Maps, verify clues, and create adventures, so they are fully prepared before they set out.

### Current Status
The first version of the data models and their methods is complete.

### Next Steps
1. Build the basic UI and navigation flow using Apple's built-in SwiftUI views.
2. Design a more polished UI in Figma, based on the existing view structure and `DESIGN.md`.
3. Implement the Figma designs in the app.
